        File format

        One row per hour, oldest first. Columns (any subset, header names are flexible): HR (heart rate), O2Sat or SpO2, Temp (°C), Resp (breaths/min). Optional: Age, Gender (1 = male, 0 = female), SepsisLabel (to compare with the recorded outcome). PhysioNet 2019 .psv files work as they are.

        Phone alerts (SMS)

        Alarm-level alerts are texted to the patient's phone number through an Android phone running SMS Gateway for Android (sms-gate.app) in Local Server mode, on the same Wi-Fi/hotspot as this laptop. No internet needed. At most one SMS per patient per interval.

        Demo time compression

        The model works on hourly data. For a live demo one "model hour" can be compressed into a few seconds; the DEMO TIME badge shows whenever this is not real time.

        Temperature calibration

        The sensor measures wrist skin temperature; "estimated temperature" = skin + offset. Measure with a thermometer and enter the reading.
